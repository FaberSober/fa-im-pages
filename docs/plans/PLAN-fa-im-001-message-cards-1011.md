## 开发说明

- 复用现有文件地址及 FilePreviewModal，保持图片和视频消息处理。
- 语音解析服务端 fileId/duration，不显示原始 JSON；切换播放停止上一条，组件卸载后停止，损坏消息提示错误。
- 卡片继承发送/接收气泡颜色，适配明暗主题。仅补齐消息展示与播放，不增加网页录音发送入口。

## Web PDF 空白反馈（2026-10-11）

- 安卓独立 H5 与 Web 弹窗使用不同入口。Web React 查看器的异步加载失败通过 `onStateChange.error` 返回，原 React 错误边界无法自动捕获，导致共享 PDF 回退未触发。
- 共享 `FileViewerDocument` 接收错误状态并转为可捕获的渲染错误，触发现有 PDF 阅读器回退；输出带组件标识的错误，保留底层诊断。缓存查看器配置，避免状态更新重新创建配置并触发重载。
- 截图不足以判断底层错误是文件请求、Worker 或解析失败；本批未进行浏览器现场诊断，具体底层原因需结合控制台错误确认。进度保持 `🔍验证中`。
- 人工验证：重新打开同一 PDF，确认正常渲染或成功切换备用阅读器；若仍失败提供控制台 `[FileViewerDocument] 文件渲染失败` 后的错误及 PDF/Worker 请求状态。回归 Office 预览和 PDF 翻页、缩放、下载。

## PDF 跨域确认与弹窗尺寸（2026-10-11）

- 控制台确认文件接口重定向至 RustFS，最终文件响应缺少 Access-Control-Allow-Origin。用户更新 RustFS CORS 配置并重启后确认 Web PDF 正常显示，底层原因已明确为跨域配置。
- 共享 FilePreviewModal 默认宽度调整为 90vw，预览区高度 calc(90vh - 140px)，默认居中，为标题及底部操作预留空间；调用方可继续覆盖 width、bodyStyle.height 和 centered，全屏入口保留。
- 差异检查通过，未执行本批编译或浏览器视觉验证；WEBMSG01 保持 `🔍验证中`。请重新打开 PDF 检查默认宽高，在小窗口及全屏/退出全屏下检查预览和关闭操作。
